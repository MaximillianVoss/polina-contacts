# Mobile Programming — Assignment 13 (Contacts)

Источник: [оригинальный скриншот](SOURCE.png) из `newhwoctober.zip`.
Ниже текст задания, без решения. Исправлено только оформление.

> Create an app that show all contacts from your device in the FlatList component (name and phone number) when a button is pressed.

На иллюстрации — список из трёх контактов с именами и номерами и кнопка `GET CONTACTS`.

## Что требуется по-русски

1. Создать мобильное приложение.
2. Читать контакты устройства после нажатия кнопки.
3. Показывать все доступные контакты в `FlatList`.
4. Для каждого выводить имя и телефон.

В источнике не требуется добавлять, изменять, удалять контакты или отправлять их на сервер. Срок сдачи и баллы на скриншоте не указаны.
