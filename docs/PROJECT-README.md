# Assignment 13 — Contacts

Самостоятельный проект Expo SDK 57 и TypeScript. Кнопка **GET CONTACTS** проверяет доступность API, запрашивает разрешение и читает все доступные страницы контактов. `FlatList` показывает имя и каждый телефон. Записи без имени или номера сохраняются.

[Исходное условие](ASSIGNMENT.md) · [Полный разбор и содержимое всех файлов](MANUAL.md)

## Запуск

Нужен Node.js 24.x. В папке проекта выполните:

```sh
npm ci
npm start
```

Откройте QR-код в Expo Go соответствующей версии на Android или iPhone. `npm run android` открывает настроенный Android-эмулятор; `npm run ios` открывает iOS Simulator на macOS. Проверка адресной книги требует мобильного устройства или эмулятора с контактами. `npm run web` показывает интерфейс и объяснение недоступности системных контактов в браузере.

## Проверка

```sh
npm run typecheck
npm test
npm run build
```

Тесты проверяют разрешения, все страницы, все телефоны, пустую книгу, ограниченный доступ iOS, стабильные ключи, ошибки, защиту от зацикливания и отмену после ухода с экрана. Мобильные сборки JavaScript доступны отдельно через `npm run bundle:android` и `npm run bundle:ios`. Это экспорт кода и ресурсов, а не APK/IPA.

## Файлы

- `App.tsx` — экран, состояния загрузки и ошибки, блокировка повторного запроса, защита после размонтирования.
- `src/contacts.ts` — модель, форматирование и постраничное чтение; не зависит от Expo и React Native.
- `src/expoContacts.ts` — адаптер официального `expo-contacts/legacy` API SDK 57.
- `src/ContactRow.tsx` — строка имени и всех телефонов.
- `tests/contacts.test.ts` — проверки с подменяемым API без чтения реальных контактов.
- `app.json` — сообщение для разрешения iOS через config plugin.

На iOS 18+ ограниченное разрешение открывает только выбранные пользователем контакты: приложение явно сообщает об этом. Если повторный запрос запрещён системой, экран предлагает изменить разрешение в настройках. Контакты не редактируются, не сохраняются на диск и не передаются по сети. Разрешение не запрашивается при запуске.

Документация API: [Expo Contacts (legacy)](https://docs.expo.dev/versions/latest/sdk/contacts-legacy/).
